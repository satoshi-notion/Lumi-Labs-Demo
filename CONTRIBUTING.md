# Contributing to Lumi Tasks API

Thanks for helping out!

## Workflow
1. Pick an issue (look for `good first issue`) and comment that you're on it.
2. Branch from `main`: `feat/...`, `fix/...`, or `docs/...`.
3. Use [Conventional Commits](https://www.conventionalcommits.org/) for messages.
4. Run `npm test` before opening a PR and link the issue with `Closes #<n>`.
5. Request a review; at least one approval is needed to merge.
